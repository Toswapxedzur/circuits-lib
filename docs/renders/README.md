# Renders

Reference renders of the parts, kept committed so the target look is retrievable (not buried in a chat
transcript). **Rule: whenever we generate a render, commit both the generating script/task AND the output PNG.**

## plastic-series-reference.png

The plastic part series in **lime**: capacitor, slide switch, press switch — the agreed look the 3D engine
matches, pixel for pixel.

- **Originally generated by** the retired `./gradlew :display:preview` viewer (`com.minecart.display.preview`,
  now removed). This is a crop of that window, kept as the agreed target look.
- **Now produced by the engine datagen** (the live path): `./gradlew :display:seedtextures` bakes the same look
  into fixed per-face sprite PNGs (`display/src/main/resources/textures/parts/`, via `SeedPartTextures` +
  `PaletteDither`, whose `litFace` is the pixel-exact successor of the old `PreviewTextures.litFace` — same
  palette, seeds, corner order), then `./gradlew :display:enginedemo` renders them from the atlas.

Note: the press switch **is** now an engine part (`press`) — the engine gained an oriented-`Quad` primitive for
its angled leaf-spring plates, so this box-only limitation no longer applies.
