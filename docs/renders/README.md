# Renders

Reference renders of the parts, kept committed so the target look is retrievable (not buried in a chat
transcript). **Rule: whenever we generate a render, commit both the generating script/task AND the output PNG.**

## plastic-series-reference.png

The plastic part series in **lime**: capacitor, slide switch, press switch — the agreed look the 3D engine
matches, pixel for pixel.

- **Generated by:** `./gradlew :display:preview` → `com.minecart.display.preview.ModelPreviewApp`
  (per-face `PreviewTextures.litFace`: conserved palette dither + object-space top-lit gradient, under
  `ModelPreviewApp`'s studio lighting). This is a crop of that window.
- **Reproduced by the engine:** `./gradlew :display:seedtextures` bakes the same look into fixed per-face
  sprite PNGs (`display/src/main/resources/textures/parts/`, via `SeedPartTextures` + `PaletteDither`, which
  ports `litFace` with each part's exact paint/seed), then `./gradlew :display:enginedemo` renders them from
  the atlas. Engine sprites are pixel-identical to this reference (same palette, seeds, corner order).

Note: the press switch is not yet ported to the engine (its leaf-spring uses angled flat quads; the engine is
box-only — needs an oriented-quad primitive).
